# AGENTS.md

This file is for any AI agent working in this repo (Claude, ChatGPT/Codex, Bolt, Grok, others).

1. Read `CLAUDE.md` for the owner, goals, rules and "via negativa" limits. It applies to all agents, not only Claude.
2. Read `HANDOFF.md` for the current state and the next step. Continue from there. Do not start from scratch and do not re-explore the whole repo.
3. Do the task. Keep changes small, on a branch named `change/short-description`.
4. Before you stop, update `HANDOFF.md`: refresh "Current state", copy the owner's last instruction, and add one line to the Log. Do this even if you did not finish.
5. If you are running low on context or must stop mid-task, write exactly where you stopped and the next step in `HANDOFF.md`.
6. Never print or commit secrets.
